# agent-harness

A personal agent harness, and a foundation to build other software on: one brain per domain owns the model calls and the data, limbs give agents their tools wherever they run, and faces (a browser tab, the phone) show the work as a map of agents and chats.

- [Vision](docs/vision.md): what it is when finished, and the six structures it is built from.
- [Plan](docs/plan.md): the milestones, what is next, and how the work runs.
- [To do](docs/todo.md): the open work, by structure.
- [Glossary](docs/glossary.md): the words, and where the code names them differently.
- [Demos](demos/README.md): what runs today, as scenarios you can watch.
