# agent-harness

Experimental process-steered workbench for a future evented agent harness.

Site: https://agent-harness.maxeonyx.com

The current goal is not to ship a narrow MVP. The repository first establishes the process, source notes, black-box test boundaries, and disposable experiment area needed to make reliable progress toward the full harness design.

Start with `docs/process/HANDOFF.md`.
