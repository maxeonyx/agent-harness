What fits. There is one vocabulary and one fold, and every reader uses them. What fits. "The parent exits only after its children confirm" holds by construction. A spawn call settles only when every member of its scope is done, and a stopping owner stops each live member with Drain(Stop(Owner)), which runs the same cascade one level down. Tool calls get a signal ladder: Stop, then SIGTERM to the command's whole process group, one second's grace, then SIGKILL; the settlement fact is the confirmation. A task with background work can't finish: it waits as Listening. That is the safe half of your ownership rule.

What doesn't yet.

  • The agent never gets a "please tidy up" turn. A stop abandons the agent's in-flight response and kills its tools. No request tells the model to wind down and ask the same of its children.
  • Not every request can be cancelled. The abort flag is read only when a stream event arrives, so connecting, waiting for headers and silent gaps can't be stopped, and ureq has no timeouts. In the journal above, the abandon landed only at FirstByte, 1.2 seconds after the interrupt.

  • No way to pass ownership to the parent. A task that wants to finish while something it started keeps running has no fact to hand that work over.
