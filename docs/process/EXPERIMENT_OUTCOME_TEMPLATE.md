# Experiment Outcome Template

An outcome doc is a curated record, not a log: it describes the experiment as accepted (or as abandoned), rewritten to current truth as the experiment evolves. Do not accumulate round-by-round review chronology — findings that were fixed are noise once fixed; only rulings, accepted limitations, and results earn a place. Rulings move to `REQUIREMENTS.md` as current truth; record them here with the user's original wording as provenance.
