# OpenCode fork as inspiration

This harness should take strong inspiration from my OpenCode fork, albeit not strict parity.

If this harness has a similar feature or behavior, then the specific behavior should match my fork of OpenCode as closely as makes sense.

Use these repos as the source of truth for that behavior:

- Workspace: `git@github.com:maxeonyx/opencode-workspace.git`
- Fork: `git@github.com:maxeonyx/opencode.git`

Look through the OpenCode workspace and fork before inventing new behavior. There are a bunch of behavior tweaks in the fork that should inform this harness, especially where we already have an equivalent feature.
