# agent-harness Vision

`agent-harness` is intended to become an evented agent harness built around
explicit face, brain, and limb roles.

The immediate vision is narrower: build the process and evidence machinery that
prevents a premature MVP from narrowing the eventual design. The first durable
product artifacts should be black-box tests and scenario primitives, not a real
provider adapter or UI.

The source notes in `docs/source-notes/` define the provisional full design
space. `docs/process/HANDOFF.md` defines the current active loop.
