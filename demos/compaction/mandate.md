This repository is a tiny Python package with no code yet; `README.md` says what it should become.

Build it yourself, without starting other agents, in two steps one after the other:
1. `textstats/wordcount.py` and `tests/test_wordcount.py`;
2. `textstats/palindromes.py` and `tests/test_palindromes.py`.

Run `./check.sh` after each step. When a step passes, compact before the next one, as your tools describe. When both pass, commit everything with git and end your turn with `compact_and_report`.
