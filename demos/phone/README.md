# phone

`demos/phone/run.sh`: Max's day from his phone at phone size, on the scripted model (free, about 40 s plus the build). It leaves the brain up with both chats.

Watch, in the shots (`demos/phone/*.ignore.png`, in the order the run takes them) and then in the open page at a phone's width:

- `new`: + opens a new chat whose directory is already the first chat's, so nothing needs typing.
- `dictated`: the sample recording dictated into the box, as the microphone would.
- `staged`: the first tap of Send stages the words above a divider, and the button reads `Send`; the second sends.
- `reloaded`: after a reload the chat is open where it was, with the reply.
- `find`: the magnifier beside fit opens the find box, the way Ctrl+K or / does at a keyboard; the first chat is listed with what matched.
- `found`: a tap opens it at the match.
